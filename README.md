## Resumo dos Conceitos Praticados

Descreva em 1 ou 2 parágrafos o que você aprendeu:
Durante o desafio **“Construa um App de Fotos de Gatos”**, aprendi a utilizar as principais estruturas do HTML para criar e organizar uma página web. Pratiquei o uso de títulos, parágrafos, imagens, links, listas e campos de formulário, entendendo melhor a função de cada tag e seus atributos.

Também aprendi a importância de organizar corretamente os elementos HTML para que a página funcione como esperado. O exercício ajudou a reforçar meus conhecimentos de HTML básico e a ganhar mais prática na criação de páginas simples.

* A principal dificuldade foi lembrar a função e a estrutura correta de algumas tags HTML e seus atributos. Também tive dificuldade em lembrar alguns termos, sendo necessário consultar a documentação para continuar o exercício.

* Quais estruturas foram mais utilizadas? As estruturas mais utilizadas foram as **tags HTML**, principalmente `<h1>`, `<p>`, `<img>`, `<a>`, `<ul>`, `<li>` e `<input>`. Também foram utilizados atributos como `src`, `href` e `alt` para configurar imagens e links.
